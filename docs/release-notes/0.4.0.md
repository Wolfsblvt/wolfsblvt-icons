# @wolfsblvt/icons 0.4.0

The Borrowed Coast Night Chart family arrives in the package. Twelve `borrowed-coast/*` glyphs are now available product icons, so the game can take its view modes, standings, places, tide and route marks from the shared catalogue instead of keeping local prototypes.

## Highlights

- **View modes:** `borrowed-coast/chart` (three rounded, asymmetric coast contours), `borrowed-coast/watch` (a watchlight over layered arcs, for what a nation can lawfully observe now) and `borrowed-coast/nations` (several pennants on one shared coast).
- **Standings:** the `borrowed-coast/no-accord`, `borrowed-coast/protected-peace` and `borrowed-coast/at-war` triptych keeps two fixed pennants and lets the water between them carry the relation.
- **Places and state:** `borrowed-coast/harbor`, `borrowed-coast/guest-mooring`, `borrowed-coast/beacon`, `borrowed-coast/tide-phase`, `borrowed-coast/control` and `borrowed-coast/deep-hull-strait`.
- The [Borrowed Coast family map](https://github.com/Wolfsblvt/wolfsblvt-icons/blob/v0.4.0/docs/product-families/borrowed-coast.md) records each glyph's meaning, the usage rules, and a 16 to 32 px light and dark contact sheet. Ordinary interface controls stay on Lucide.
- Every glyph inherits `currentColor`; state colour and wording remain the consumer's job.

```astro
---
import { ProductIcon } from "@wolfsblvt/icons/astro";
---

<ProductIcon name="borrowed-coast/watch" label="Watch" />
```

## Upgrade

```bash
npm install @wolfsblvt/icons@0.4.0
```

No existing name changed meaning or geometry. `0.4.0` also carries everything from `0.3.0`, including the `bluesky` brand and the Wolfsblvt Works glyphs.

## Credit

The family was drawn and prepared by Nyxara, from Wolf's owner-ratified Night Chart design, including his revision of `chart` to rounded coast contours.

## Proof and current limits

The release source passed the repository verification suite, including a real Astro consumer build and a clean consumer that installs the packed tarball before building through its public exports. It is published from GitHub Actions through npm Trusted Publishing and carries npm provenance.

The `borrowed-coast/*` names become compatibility-bearing once published; a material change to a glyph's meaning or silhouette needs its own visual contribution. `0.4.0` is still an early package release, not a stability promise.
