# @wolfsblvt/icons 0.5.0

The TunnelTend glyph arrives in the package. `tunneltend/brand` is now an available product icon, so the Works website's contact picker, and any other Works surface that shows TunnelTend, can take it from the shared catalogue instead of keeping a local copy.

## Highlights

- **`tunneltend/brand`** is The Fold, TunnelTend's mark of two independent rounded paths nested in a stable turn, for picker, link and provider-style slots where the formal lockup does not fit. Its path data is TunnelTend's own tintable master, carried unchanged: it was already a 24×24, 2px round-stroke, `currentColor` line mark.
- The [TunnelTend family map](https://github.com/Wolfsblvt/wolfsblvt-icons/blob/v0.5.0/docs/product-families/tunneltend.md) records the meaning, source commit and hash, usage rules, and a 16 to 32 px light and dark contact sheet beside Lucide references.

```astro
---
import { ProductIcon } from "@wolfsblvt/icons/astro";
---

<ProductIcon name="tunneltend/brand" label="TunnelTend" />
```

## Upgrade

```bash
npm install @wolfsblvt/icons@0.5.0
```

No existing name changed meaning or geometry. `0.5.0` also carries everything from `0.4.0`, including the Borrowed Coast Night Chart family.

## Proof and current limits

The release source passed the repository verification suite, including a real Astro consumer build and a clean consumer that installs the packed tarball before building through its public exports. It is published from GitHub Actions through npm Trusted Publishing and carries npm provenance.

The package carries only the monochrome line glyph. The coloured Fold, wordmark, lockups, favicon and its heavier small-size variant stay in TunnelTend's own brand bundle. `tunneltend/brand` becomes compatibility-bearing once published. `0.5.0` is still an early package release, not a stability promise.
